# Agent Rules for the Workspace

## Blog Posts
When asked to create or modify a blog post, you MUST STRICTLY adhere to the guidelines in `.kiro/steering/blog-post-guidelines.md`.
1. ALWAYS use the `<article class="blog-prose">` wrapper.
2. NEVER use brutalist or terminal styling (e.g. `border-black`, `> ` prefixes). Use standard semantic HTML (`<h2>`, `<p>`).
3. Trust that the `blog-prose` CSS handles the styling correctly.
